# Changelog

All notable changes to CodePet AI are documented in this file.

## [Unreleased] - 2026-11-07

### Added
- Interactive virtual pet character.
- Pet animation system.
- Energy and Happiness statistics.
- Pet mood system.
- EXP and level progression.
- Feed, Sleep, Play, and Interact actions.
- Randomized pet messages.
- Passive pet behavior.
- Persistent pet state using VS Code GlobalState.
- Offline time simulation with a 24-hour maximum.
- Coding activity detection.
- Programming language identification.
- File opened, edited, saved, and closed event detection.
- CodePet Coding Activity Output Channel.

- Webview communication.
- Pet statistics visualization.
- State persistence and validation.
